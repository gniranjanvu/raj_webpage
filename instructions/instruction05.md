### Certification Form Fields Summary

```yaml
Fields:
  Details:
    - name: string (required) - Certification name
    - issuer: string (required) - Issuing organization
    - issuer_logo_url: file/URL (optional)

  Dates:
    - issue_date: date (required)
    - expiry_date: date (optional)
    - no_expiry: boolean - Checkbox for no expiration

  Credentials:
    - credential_id: string (optional)
    - credential_url: URL (optional) - Verification link

  Certificate:
    - certificate_file_url: file/URL (optional) - PDF or image

  Content:
    - description: textarea (optional)
    - skills: relation array (optional) - Linked skills

  Settings:
    - display_order: number
    - is_published: boolean
```
